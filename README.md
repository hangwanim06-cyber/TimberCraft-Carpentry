# TimberCraft Carpentry Website

## About the Project

TimberCraft Carpentry is a small fictional carpentry business based in Johannesburg. The website provides information about the business, its services and how customers can contact the business or submit an enquiry.

## Purpose of the Website

The purpose of the website is to provide customers with an easy way to:

- Learn about TimberCraft Carpentry
- View the services offered
- Request a quotation
- Find contact information
- Submit an enquiry

## Website Pages

The website contains five main pages:

1. **Home** (`index.html`) - Introduces TimberCraft Carpentry and provides links to the main services and enquiry page.

2. **About Us** (`about.html`) - Provides information about the business, its mission, vision, values and team.

3. **Services** (`services.html`) - Provides information about the carpentry and woodworking services offered.

4. **Enquiry** (`enquiry.html`) - Allows customers to submit a service enquiry and provide project details.

5. **Contact** (`contact.html`) - Provides business contact information, locations, opening hours and a contact form.

## Technologies Used

- HTML5
- CSS3
- JavaScript
